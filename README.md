# Домашнее задание к работе 6.
## Описание
Программа проверяет, попадает ли точка с заданными координатами (x,y) в заштрихованную область на графике.
## 1. Алгоритм и блок-схема 
### Алгоритм 
1. **Начало.**
2. **Ввести** координаты \(x\) и \(y\).
3. **Проверить**, что одновременно:
   - \(y <= x + 5),
   - \(x^2 + y^2 >= 3),
   - \(x <= 0),
   - \(y >= 0).
4. **Если всё верно** — вывести «Лежит», **иначе** — «Не лежит».
5. **Конец.**

## 2. Реализация программы
 '''c
#include <stdio.h>
#include <locale.h>

int main() {
    setlocale(LC_ALL, "RUS");
    float x, y;
    printf("Введите x и y: ");
    scanf("%f %f", &x, &y);
    if (y <= x + 5 && x * x + y * y >= 3 && x <= 0 && y >= 0)
        printf("Лежит\n");
    else
        printf("Не лежит\n");
    return 2;
}
